# 데이터 로드 및 기본 탐색

거래 파일 앞부분 10만 행에 고객·상품 정보를 왼쪽 조인하면 10만 행, 9열이다. 이 표본의 거래일은 2018-09-20부터 2018-09-22까지다. 거래 기록 수는 그대로 유지됐으며 상품명은 모든 행에 연결됐다.

연령은 584행에서, 멤버십 상태는 1,068행에서 비어 있다. 거래 행 기준으로 연령 결측이 0.584%이므로 멤버십 그룹별 중앙값으로 채우고 그룹 통계가 없으면 전체 중앙값을 사용한다.

표본 가격의 중앙값은 0.0254이며 IQR 경계 밖에는 7,895행이 있다. 가격 분포는 표본의 초기 기간에 한정되므로, 파이프라인에서 이상치 후보를 표시하고 RFM은 원본 가격과 전체 거래 기간을 기준으로 계산한다.
